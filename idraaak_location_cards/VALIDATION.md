# Validation — 2026-10-27

Version: 0.1.0 preview. Intended compatibility: QGIS 3.34 through 3.x.

## Completed

- Six dependency-free Python regression tests passed: coordinate order in Google Maps URLs; invalid, infinite and NaN coordinates; boundary values; HTML injection through names and titles; Arabic/English output; empty and excessive exports.
- Five integration tests passed using **real QGIS 3.34.4-Prizren Python bindings on Ubuntu 24.04 and offscreen Qt**. The tests construct real memory layers and widgets; QGIS itself is not mocked.
- Integration checks covered the plugin action/menu lifecycle, dialog creation and an actual HTML export, selected-subset behavior, no fallback to exporting all points when the selection is empty, EPSG:3857 to EPSG:4326 transformation against independently computed coordinates, null-name fallback, out-of-range points, and multipart rejection.
- The small `iface` adapter represents the QGIS main-window interface in these headless tests. File picking and the success message are intercepted to permit unattended export. A full interactive QGIS desktop session was not run.
- Arabic and English print samples were rendered to PDF for inspection. The Arabic output and the real Qt dialog were visually inspected. Arabic card numbering flows from right to left; coordinates remain left to right.
- Python syntax and install ZIP structure checked; generated bytecode and temporary files excluded. Flake8 reported zero findings and Bandit reported zero findings. HTML layout is stored in a local template, without remote dependencies.

## Reproduce checks

From the directory containing the `idraaak_location_cards` package:

```sh
python -m unittest discover -s idraaak_location_cards/tests -p test_cards.py -v
```

For integration checks, use the Python environment supplied with a supported QGIS installation, with its QGIS bindings on PYTHONPATH:

```sh
QT_QPA_PLATFORM=offscreen python idraaak_location_cards/tests/test_qgis.py
```

The integration script optionally reads `QGIS_PREFIX_PATH` and `LOCATION_CARDS_TEST_SCREENSHOT`. It performs local tests only and writes its export to a temporary folder.
